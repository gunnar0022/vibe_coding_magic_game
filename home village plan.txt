HOME VILLAGE IMPLEMENTATION DIRECTIVE

#################

OBJECTIVE
Implement a SINGLE LOADABLE HOME VILLAGE AREA that meaningfully demonstrates world-building depth, NPC behavior, dialogue systems, traversal, and interior spaces using PLACEHOLDER ASSETS.

This is not a content dump.
This is a SYSTEMS + FEELING exercise.

The goal is to create a village that feels lived-in, coherent, and reactive using existing engine architecture.

#################

SCOPE BOUNDARIES

ONLY ONE VILLAGE AREA

PLACEHOLDER VISUAL ASSETS ARE ACCEPTABLE AND EXPECTED

FOCUS ON DEPTH, NOT SCALE

BUILD SYSTEMS THAT CAN BE EXTENDED LATER

#################

CORE DELIVERABLES

AREA STRUCTURE

Create a new loadable area representing a small village

Integrate with existing area loading / transition systems

Define clear village boundaries

Add intentional terrain layout (paths, open spaces, fenced areas)

Terrain should subtly communicate how the village is used (gathering, rest, travel)

PLACEHOLDER ENVIRONMENT ASSETS

Houses (X’s house, Y’s house, etc.)

Wooden fences

Bushes / plants

Simple props (signs, wells, crates, etc.)

Assets may be visually simple but must be semantically distinct.

BUILDINGS AND INTERIORS

At least one enterable building

Interactable door that transitions the player indoors

Interior area with basic placeholder assets (table, chair, etc.)

Interior space should feel functionally different from outdoors

Use the same world rules (movement, collision, interaction)

NPC SYSTEM EXPANSION

Implement multiple NPCs with:

Name

Personality descriptor

Internal backstory note (stored in data or comments, NOT shown to player)

Dialogue trees

Dialogue that reflects personality and world state

Pathing behavior:

Walk to a location

Pause / idle

Return or change route

At least ONE NPC must:

Ask the player a question

Present a YES / NO choice

Branch dialogue based on the response

Dialogue should feel intentional, not generic.

WORLD FEEL AND LORE INTEGRATION

Use the World Lore Overview as tonal guidance.

When designing NPCs, spaces, and dialogue, consider:

How people survive here

What they fear

What they believe about magic

What they don’t say directly

Depth should emerge from small details.

#################

PROCESS EXPECTATIONS

Approach this recursively

Break broad problems into smaller solvable systems

Reuse existing architecture wherever possible

Add new systems only when necessary

Prefer data-driven solutions

If a decision is ambiguous:

Make a reasonable assumption

Document it briefly in code comments or notes

#################

NON-GOALS

No combat required

No advanced AI

No final art

No full quest system

#################

SUCCESS CRITERIA

At the end of this task, the player should be able to:

Enter a village

Walk through a space that feels intentionally designed

Meet NPCs who move, speak, and react believably

Enter at least one building

Experience a small but cohesive slice of the world

#################

BEGIN WITH STRUCTURE FIRST
Then populate meaningfully.
