SYMBOL REGISTRY
================

Each symbol can be cast alone (solo spell) or combined with one other symbol (combo).
Symbols are learned from rune stones or NPCs in the world.

DESIGN DECISIONS
-----------------

- 闇 coexists with 空. 闇 = corruptive darkness, 空 = neutral emptiness.
- 炎 is an upgraded 火. Costs more, does more.
- 切 is a combo modifier (dud alone). Used with 風, 水, etc. for elemental cuts.
- 動 has been REMOVED from the design.
- 石 sits alongside 土. 石 is for offensive physical magic.
- 風 is "wind" -- cutting wind, not gentle air.
- 電 is basic electric, 雷 is upgraded electric.

Element Mappings for Reaction System:
- 電 and 雷 both map to Element.ELECTRIC (different intensities)
- 闇 maps to Element.DARK (distinct from 空 which maps to "void" -- may need new Element.VOID)
- 炎 maps to Element.FIRE (higher intensity variant)
- 切 maps to no element (physical modifier)
- 石 maps to Element.EARTH (physical variant)
