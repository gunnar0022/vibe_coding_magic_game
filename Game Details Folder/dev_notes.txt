Next prompt:

Implement the SPELL NOTEBOOK (journal) tab of the menu.

This system is a player-facing reference book for BASE SPELLS ONLY (individual symbols). Spell combinations do NOT get pages.

CORE FUNCTIONALITY
Each unlocked base spell (symbol) has a dedicated entry in the notebook. Each entry is presented as a two-page spread:
Left page: base information (symbol, default keywords, default description)
Right page: player-editable notes

Default spell text and initial keywords come from the spell’s existing JSON data. This default text may include basic mechanical observations for now, but should be structured so it can later vary based on how the spell was discovered (taught by NPC vs found in the wild).

Players can freely add, edit, and delete their own notes. Notes may be incorrect; the system does not validate player understanding.

If the player fills the initial notes page, they may add up to TWO additional note pages for that spell. Page order should be:
Spell info page → Note page → Optional note page → Optional note page → Next spell

INDEX + SEARCH
The notebook opens directly to an INDEX page (no cover animation for now).

The index displays:

Spell symbol

Associated keywords (shown next to the symbol)

Page number reference

Clicking a spell in the index jumps directly to that spell’s page.

If the number of spells exceeds index capacity, additional index pages should be created dynamically.

The index includes a SEARCH field that filters spells by:

Keywords (default + player-added)

Symbol text itself (e.g. typing 火 should return the fire spell)

Search results should visually highlight matching entries rather than hiding non-matches.

Players can assign their own keywords to spells. Keywords have a reasonable character limit.

NOTEBOOK BEHAVIOR
The notebook is strictly informational and separate from spell casting.

It cannot be opened during combat (if combat exists later).

Time continues to pass while the notebook is open (no pausing the game loop).

INPUT AND UI
Navigation should feel like paging through a book, but optimized for usability.
Index navigation and spell selection are mouse-based.
Typing is required only for search and notes.

DATA & PERSISTENCE
Notebook state must persist across sessions, including:

Player-written notes

Player-added keywords

Page expansions per spell

The game should auto-load the most recent save on launch (no main menu yet).
