   - Notebook opens to index page showing all known spells
   - Index displays: symbol character, keywords, page number
   - Search field filters by keywords and symbol text
   - Matching entries are highlighted, non-matches dimmed
   - Dynamic index pages if spells exceed capacity (8 per page)

3. NAVIGATION (DONE)
   - Click spell in index to jump to that spell's page
   - A/D or Left/Right arrows to turn pages
   - Prev/Next buttons on spell pages

   - ESC closes notebook

4. INPUT/UI (DONE)
   - J key opens journal directly from gameplay
   - ESC menu has "Spell Journal" option (now enabled)
   - Mouse-based index navigation
   - Keyboard typing for search and notes
   - Click on note area to edit

5. DATA PERSISTENCE (DONE)
   - Player notes saved with game
   - Player-added keywords saved
   - Known spells list persists
   - Integrated with save_system.py

6. GAME INTEGRATION (DONE)
   - SpellNotebook integrated into Game class
   - Time continues while notebook is open (world updates)
   - Player input blocked while notebook open
   - Learned spells auto-added to notebook (both initial and NPC-taught)
