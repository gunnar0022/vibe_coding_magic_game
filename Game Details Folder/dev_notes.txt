POLISH FEATURES IMPLEMENTED:
----------------------------

1. AUTO-DELETE NODES ON REMOVAL
   - When right-clicking or dragging a node off the radial menu, the node data is automatically deleted
   - No orphaned nodes left in the Menu Structure panel
   - Clear All also recursively deletes nested nodes

2. RETURN SLOT VISUAL
   - In nested menus, the return slot shows a locked green appearance
   - Displays a left-pointing arrow and "BACK" label
   - Cannot be interacted with (hover/click/drag ignored)
   - Thicker border to indicate locked state

3. SLOT COUNT DISPLAY
   - Root menu shows: X/8 slots
   - Nested menus show: X/7 slots (since 1 is reserved for return)
   - Count shown in center of radial preview and in node tree

4. SEARCH BAR
   - Located at top of Known Spells panel
   - Filters by spell ID, name, or character
   - Click to activate, ESC or Enter to deactivate
   - Placeholder text when empty

5. NODE RENAMING
   - Double-click node in Menu Structure panel to rename
   - Or use "Rename" button
   - 12 character maximum
   - Input sanitization: only alphanumeric, spaces, underscores, hyphens, dots
   - Shows character count during editing
   - Enter confirms, ESC cancels

6. DRAG AND DROP
   - Click and drag spells from list to slots
   - Click and drag spells between slots (swaps if destination has content)
   - Double-click spell in slot to start dragging
   - Visual drag preview follows cursor
   - Drop on slot to assign
   - Drop outside radial area to delete (spell returns to unassigned list)
   - Dragging a node off the menu deletes the node entirely

7. DOUBLE-CLICK BEHAVIOR
   - On node slot: enters the submenu
   - On spell slot: starts dragging the spell (same as single-click)
   - On node in tree panel: opens rename dialog
   - On return slot: navigates to parent menu

8. DYNAMIC RETURN SLOT
   - When a node is dragged to a new slot position, the return direction automatically updates
   - Return slot is always opposite to the entry direction (where node sits in parent)
   - Example: Move node from N slot to E slot -> return changes from S to W
   - Single-click on node slot starts drag (like spells)
   - Double-click on node slot enters the submenu

CONTROLS SUMMARY:
-----------------
- Drag: Move spells/nodes between slots or from list
- Double-click: Enter node / Start drag / Rename
- Right-click slot: Remove content (deletes nodes entirely)
- Click search box: Activate search
- ESC: Cancel current action / Close dialogs / Save and exit
- Enter: Confirm rename
