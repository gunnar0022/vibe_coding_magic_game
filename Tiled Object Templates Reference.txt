================================================================================
  TILED OBJECT TEMPLATES REFERENCE
  For use with the Magic Game TMJ pipeline
================================================================================

HOW TO USE THIS FILE:
  1. In Tiled, create an Object Layer called "entities"
  2. Use the Point tool (or Rectangle for zones) to place objects
  3. Set the Class/Type field to the value shown below
  4. Add each Custom Property listed (click + in the Properties panel)
  5. Save as a template for reuse via right-click > Save As Template

NOTE ON COORDINATES:
  Tiled uses pixel coordinates. Your tiles are 16x16.
  The game loader will convert: tile_x = pixel_x / 16, tile_y = pixel_y / 16
  So just place points visually where you want them.

NOTE ON ENEMY SPAWNER TYPES:
  Tiled custom properties don't support nested arrays/objects.
  For enemy_types, use a comma-separated string format.
  The game loader will parse "slime:80,skeleton_archer:20" into the
  weighted type list.

================================================================================
  RECTANGLE OBJECTS (use the Rectangle tool)
================================================================================

--------------------------------------------------------------------------------
29. ZONE TRANSITION
--------------------------------------------------------------------------------
   Class/Type:  zone_transition
   Properties:
     target_area   (string)  =  home_village
     target_entry  (string)  =  from_forest
     zone_id       (string)  =  to_village
   Notes:       Draw a rectangle spanning the full passage area.
                Player auto-teleports when stepping into the zone.
                Example: a 4-tile-wide strip at the map edge.

--------------------------------------------------------------------------------
30. ENTRY POINT
--------------------------------------------------------------------------------
   Class/Type:  entry_point
   Properties:
     entry_id    (string)  =  default
   Notes:       Point where player arrives from another area.
                Use names like: default, from_village, from_forest,
                from_elder_house, south_entrance
                Place one "default" per map as the fallback spawn.

--------------------------------------------------------------------------------
31. COLLISION ZONE (optional, if not using tile properties)
--------------------------------------------------------------------------------
   Class/Type:  collision
   Properties:  (none)
   Notes:       Draw rectangles over areas players can't walk.
                Use for irregular blocking zones that don't align
                with individual tiles (lake shores, cliff edges, etc.)


================================================================================
  MAP-LEVEL PROPERTIES
================================================================================

   Set these on the Map itself (Map > Map Properties in Tiled):

     area_id            (string)  =  forest
     name               (string)  =  The Forest
     description        (string)  =  A mysterious forest...
     max_enemies        (int)     =  6
     spawn_wave_interval (float)  =  120.0


================================================================================
  QUICK COPY-PASTE PROPERTY TABLE
================================================================================

  Below are tab-separated values you can reference when adding properties.
  Format: property_name [TAB] type [TAB] default_value

  For enemy_spawner:
    enemy_types         string      slime:80,ember_sprite:20
    spawn_chance        float       1.0
    respawn_time        float       60.0

  For npc:
    template            string      village_elder

  For rune_stone:
    symbol              string      earth

  For ground_item:
    item_id             string      health_potion

  For door:
    target_area         string      elder_house
    target_entry        string      default
    door_id             string      my_door

  For zone_transition:
    target_area         string      home_village
    target_entry        string      from_forest
    zone_id             string      to_village

  For entry_point:
    entry_id            string      default
